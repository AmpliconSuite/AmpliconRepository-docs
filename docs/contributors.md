# People Behind AmpliconRepository

AmpliconRepository is a collaborative scientific software project developed by members of the Bafna and Mesirov labs. Its development has included the web application, data and storage services, computational analysis methods, interactive visualizations, and production infrastructure.

## Project leadership

**[Jens Luebeck](https://github.com/jluebeck) — Project lead and lead developer**<br>
Jens sets the scientific and technical direction for AmpliconRepository, defining how AmpliconSuite methods and outputs are represented, analyzed, and exposed through the site. His engineering work includes core project and sample views, interactive visualizations, co-amplification analysis, and integration with AmpliconSuiteAggregator. He currently leads development, deployment, and maintenance.

## Architecture and core engineering

**[Ted Liefeld](https://github.com/liefeld) — Lead architect**<br>
Ted designed and implemented much of the full-stack application architecture: identity and access control; project creation, sharing, versioning, and deletion; MongoDB and DocumentDB access; S3-backed data delivery; background processing; administrative tooling; and production and release infrastructure. He also built and repeatedly refined major frontend workflows and introduced performance, caching, and operational-reliability improvements throughout the system.

**[Edwin Huang](https://github.com/edwin5588) — Core engineer**<br>
Edwin built major portions of the ingestion and project-data pipeline, including upload APIs, aggregation integration, project creation and version history, project aliases, metadata ingestion, downloads, and project statistics. He also implemented IGV integration and other sample-page interactions and later developed the feature- and metadata-aware search system.

**[Forrest Kim](https://github.com/forrestkim) — Core engineer**<br>
Forrest established much of the early application and operational foundation, including MongoDB integration, the initial feature and search interfaces, server deployment tooling, UUID-based project handling and deletion, streaming project and sample downloads, usage reporting, and administrative quality checks.

**[Thorin Tabor](https://github.com/tmtabor)** contributed to the project schema and validation system, along with other platform development.
